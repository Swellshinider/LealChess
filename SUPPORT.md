# Support

Use the structured
[question form](https://github.com/Swellshinider/LealChess/issues/new?template=question.yml) for
questions about using LealChess, local development, or contributing. Search existing issues first
and do not include private games, credentials, or other sensitive information.

Report bugs with the bug form and propose product changes with the feature form. Disclose security
problems only through
[private vulnerability reporting](https://github.com/Swellshinider/LealChess/security/advisories/new).
